# Центр инженерной биологии / Center for Engineering Biology

Одностраничный сайт исследовательского проекта. Без фреймворков и сборщиков. HTML
генерируется небольшим скриптом на стандартной библиотеке Python из одного файла
контента на язык, поэтому разметку не нужно править в нескольких местах.

Сайт публикуется через GitHub Pages. Домен: engineeringbiology.ru.

## Структура репозитория

```
src/
  build.py               генератор: шапка, подвал, метаданные, sitemap, robots
  content/
    ru/page.html         содержание страницы (RU), разделы без <main>
    en/page.html         содержание страницы (EN)
assets/
  styles.css             таблица стилей
  app.js                 тема, мобильное меню, интерактивный цикл
  fonts.css              self-hosted шрифты
  fonts/                 Source Serif 4 и IBM Plex Mono, SIL OFL 1.1
  people/                фотографии команды и консультантов
index.html               сгенерированная страница RU
en/index.html            сгенерированная страница EN
sitemap.xml, robots.txt  генерируются
og.jpg                   изображение предпросмотра ссылки
```

Правки вносятся в `src/`, затем страницы пересобираются. Сгенерированные `index.html`
и `en/index.html` тоже коммитятся, чтобы GitHub Pages отдавал их без сборки.

## Как запустить локально

```
python3 src/build.py
python3 -m http.server 8137
```

Открыть http://127.0.0.1:8137/. Нужен только Python 3, внешних зависимостей нет.

## Как редактировать

Страница состоит из секций внутри `src/content/ru/page.html` и `src/content/en/page.html`:

- `hero` — название, тезис, интерактивный цикл;
- `#engineering` — что такое инженерная биология в проекте;
- `#research` — направления и запись эксперимента `EB-AGE-001`;
- `#method` — семь шагов цикла (раскрываются по нажатию);
- `#goals` — на что опирается проект;
- `#team` — команда и консультанты;
- `#about` — о центре.

Пункты меню задаются в `NAV` в `src/build.py` и ссылаются на `id` секций.

## Как добавить направление или эксперимент

Направление — блок `<details class="dir">` рядом с существующими. Статус брать из
небольшого набора: гипотеза, модель, пилот, нужна репликация, реплицировано. Не
показывать направление активным, пока работа не идёт.

Запись эксперимента — блок `<details class="acc">` с полями: вопрос, гипотеза,
состояние системы, модель, предсказание, протокол, результат, ошибка предсказания,
ограничения, статус. Пустые поля не заполнять выдуманными данными.

## Как добавить человека

Карточка команды — `article.person` с фото `.person__photo` (пропорция 3:4, ширина
до 168 px), ролью и короткой биографией. Консультанты — блок `.expert` с фото 72 px,
не увеличивать ими состав команды. Фотографии кладутся в `assets/people/`.

## Как добавить изображение и атрибуцию

Проверить лицензию, положить оптимизированный файл (WebP и, при необходимости, JPEG
fallback), использовать `<picture>` с `srcset`. Атрибуция указывается в подписи и в
строке `credits_note` в `src/build.py`. Не использовать AI-generated изображения как
замену реальным научным кадрам. Правь только технически, лица не менять.

## Как обновить RU и EN

Русская и английская версии независимы: `src/content/ru/page.html` и
`src/content/en/page.html`. Общий каркас и метаданные — в `src/build.py`. Не публиковать
машинный перевод низкого качества.

## Как собрать и задеплоить

```
python3 src/build.py
git add -A
git commit -m "..."
git push
```

GitHub Pages отдаёт файлы из ветки `main` в корне. Пока DNS домена не переключён на
GitHub, файл `CNAME` держать не нужно. Если у регистратора включён редирект
`engineeringbiology.ru → *.github.io`, а в репозитории лежит `CNAME`, возникает петля
редиректов и сайт не открывается.

Порядок подключения домена:
1. У регистратора отключить переадресацию домена на `*.github.io`.
2. Прописать A-записи для `engineeringbiology.ru` на 185.199.108.153, 185.199.109.153,
   185.199.110.153, 185.199.111.153.
3. Дождаться, пока `engineeringbiology.ru` начнёт отвечать кодом 200.
4. Добавить файл `CNAME` с содержимым `engineeringbiology.ru` и включить Enforce HTTPS.

## Технические решения

Документный стиль: белый фон, почти чёрный текст, Source Serif 4 для текста и
заголовков, IBM Plex Mono для подписей и обозначений, классические синие ссылки.
Один статический генератор на стандартной библиотеке, ноль внешних зависимостей.
Интерактивные блоки сделаны на нативных `<details>`, поэтому работают без JavaScript;
JS отвечает только за тему, мобильное меню и переключение шагов цикла.
